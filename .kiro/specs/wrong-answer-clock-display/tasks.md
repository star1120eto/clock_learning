# Implementation Plan: wrong-answer-clock-display

## Task Format Template

各タスクは能力・成果で記述し、要件IDで紐付ける。本機能は ClockController → ClockPainter → ClockWidget → GameScreen → テストの順で依存するため、1 と 2 は並行可能、3 以降は直列が自然。

---

## 1. 時計コントローラに表示用の時刻状態を返す処理を追加する

- [x] 1. 指定した時刻（時・分）に対応する針の位置だけを持つ表示用の状態を返す API を追加する
- [x] 1.1 (P) 既存の角度計算を再利用し、渡された時・分から針の角度を算出して表示専用の状態を返す。内部の操作状態は変更しない（副作用なし）
  - _Requirements: 1.1, 1.2_

---

## 2. 時計描画で不正解時に文字盤を緑で描画する

- [x] 2. 不正解時は文字盤を緑、それ以外は白で描画するようにする
- [x] 2.1 (P) 文字盤の背景色を呼び出し側から指定できるようにし、指定が「緑」のときは緑、「白」のときは従来どおり白で描画する。指定が変わったときは再描画する
  - _Requirements: 2.1, 2.2, 2.3_

---

## 3. 時計ウィジェットで不正解表示用のオプションと操作無効化を追加する

- [x] 3. 不正解表示時は正解の時刻を表示し、ドラッグ操作を無効にする
- [x] 3.1 不正解表示用のフラグと正解の時・分を受け取り、フラグが有効なときは表示用の状態を描画に渡し、時計のドラッグ操作を受け付けないようにする
  - _Requirements: 1.1, 1.2, 2.1, 3.1_
- [x] 3.2 文字盤の色指定（緑/白）を描画に渡す。不正解表示時は緑、それ以外は白とする
  - _Requirements: 2.1, 2.2, 3.2_

---

## 4. ゲーム画面で不正解時に時計へ正解時刻と緑背景を渡す

- [x] 4. 不正解時のみ時計に正解の時刻と緑の文字盤を適用する
- [x] 4.1 回答が不正解のとき、現在問題の正解の時・分と「文字盤を緑にする」指定を時計ウィジェットに渡す。正解時および回答前は従来どおり（正解表示なし・文字盤は白）とする
  - _Requirements: 1.1, 1.3, 2.1, 2.2, 2.3, 3.2, 3.3_

---

## 5. 既存挙動の維持確認とテストの整備

- [x] 5. 不正解時の正解表示・緑背景と、正解時・回答前・次問題後の従来挙動が正しく動作することを保証する
- [x] 5.1 表示用の状態を返す処理が、既存の初期化で得る針の角度と一致することを単体テストで検証する
  - _Requirements: 1.1, 1.2_
- [x] 5.2 文字盤の色指定に応じて緑/白が切り替わることを描画の単体テストまたは golden テストで検証する
  - _Requirements: 2.1, 2.2, 2.3_
- [x] 5.3 不正解時に時計が正解の時刻を指し文字盤が緑になること、および「つぎのもんだい」で次に進んだあと時計が従来表示に戻ることを Widget または統合テストで検証する
  - _Requirements: 1.1, 1.2, 1.3, 2.1, 2.2, 2.3, 3.1, 3.2, 3.3_
